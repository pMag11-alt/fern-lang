Fern in two minutes

      
    

    

      

        
Basics


let name = "Fern"        // a variable
const max = 10           // can't be reassigned
print("Hi, ${name}!")    // string interpolation
let xs = [1, 2, 3]       // lists: xs[0], xs[-1]
let m = {a: 1, "b c": 2} // maps: m.a, m["b c"]

        
Semicolons are optional; a line break ends a statement. Only false and nil are
          falsy.

      

      

        
Control flow


if x > 0 { ... } else if x < 0 { ... } else { ... }
while i < 10 { i += 1 }
for item in xs { ... }       // also strings and map keys
for i in range(5) { ... }    // break, continue

      

      

        
Functions


fn add(a, b) { return a + b }
fn square(x) => x * x
let twice = fn(f, x) => f(f(x))
xs |> map(square) |> sum     // x |> f(y) is f(x, y)

        
Functions are values and closures: they remember the variables around them.
